# Binary Lab

A single-file, browser-based teaching resource for 8-bit binary numbers.

## Activities

1. **Count in binary:** Start at 00000000, count up to 255, use Play/Pause, manual Next/Back, Reset, and speed slider. Changed bits flip.
2. **Teacher reveal:** Generate an 8-bit pattern, keep its decimal value hidden until **Show answer**, then display a running sum for each place value (including 0s).
3. **Student challenge:** Generate a new 8-bit pattern, type the decimal answer, check it, and see a place-value breakdown.

## Publish with GitHub Pages

1. Create a public repository called `binary` on GitHub.
2. Upload `index.html` and `README.md` to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, `main`, and `/ (root)`; save.
4. Visit `https://YOUR-USERNAME.github.io/binary/` after deployment.

No build tools, packages, accounts, or external dependencies required.
